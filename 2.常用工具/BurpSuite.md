- 实现自动化漏洞扫描
- 暴破登录表单

- 插件扩展，自动化测试脚本开发

##### BP代理模块——用于拦截和分析浏览器或客户端发送到服务器的HTTP/HTTPS请求，以及服务器返回的响应

- 拦截
  - on/off
  - Forward：放行
  - Drop：丢弃
- HTTP历史记录——所有经过bp的流量
  - 挖洞：拦截关闭，去看历史记录
- WebSockets历史——持久连接的通信协议
  - 实时聊天/即时通讯（如在线客服、社交软件聊天）
  - 实时数据更新（如股票行情、体育赛事比分）
  - 多人在线协作工具（如文档共同编辑）
  - 实时游戏（如多人在线小游戏）
  - 监控系统（如实时日志、设备状态监控）
- Match and replace匹配和替换
  - 请求和响应流量经过Burp时，自动匹配特定内容并替换为自定义值
  - 修改UA（User-Agent）——模拟不同浏览器或设备
  - 替换Cookie——自动带上自己的测试Cookie
  - 修改Host/Header字段——用于内网穿透或目标重定向测试
  - 替换响应内容——比如去掉CSP头，方便测试XSS



##### BP重放模块——用于手工修改和重放请求，观察目标服务器的响应变化

- 作用
  - 调试参数、测试漏洞（SQLi、XSS、越权等）
  - 手工修改Cookie、Header、Body数据
  - 比较不同请求的响应差异
  - 复现和验证漏洞

- 使用方法
  - 打开靶场
  - 抓取对应的数据报，在对应的数据包 右键——Send to Repeater（发送到重放器）
  - 找重放模块，点击发送即可
- 场景
  - 点赞  一人点一次
  - 修改只能用一次的数据，如用户名、IP   
  - 不断修改、不断点赞



##### BP爆破模块——自动化攻击工具，用于对Web应用的参数、接口或功能进行批量测试，以发现漏洞、枚举资源或爆破认证信息

- 工作原理
  - 工作流程基于"请求模版+payload注入+响应分析"的逻辑
  - 捕获数据——标记位置——配置字典——设置规则——开始攻击——分析结果
- 爆破使用
  - 捕获数据：通过 Burp Proxy 拦截目标请求（如登录表单提交、API 查询），或在 Burp History 中找 到目标请求，右键选择 “Send to Intruder”
  - 标记位置：在 Intruder 的 “数据包” 中，通过鼠标选择要枚举的地方点击 “添加” 标记攻击位置（如 username=adminpassword=§123456§）
  - 配置字典：在 “Payload” 标签页中，为每个标记的位置配置字典
  - 配置规则：在 “资源池” 标签页中配置线程数、延迟、Grep 关键词等
  - 开始攻击：点击 “开始攻击” 即可运行
  - 分析结果：根据返回数据包判断结果
    - 状态码（如 200→成功，403→禁止）
    - 响应长度（不同长度可能代表有效 / 无效 Payload）
    - 响应时间（如 SQL 注入可能导致延迟）
    - Grep 匹配结果（关键词标记）



##### BP爬虫功能——用于自动探索和映射 Web 应用程序结构的重要工具，帮助发现应用程序中的页 面、链接、表单等资源

- 工作原理

  主动爬虫：主动爬虫会主动向目标服务器发送请求以获取页面内容，它通过模拟用户的操作，如点击 链接、提交表单等，构造并发起 HTTP 请求，并解析这些响应来进一步发现和探索网页结构。这种方 式能够主动深入网站，发现一些复杂的页面、隐蔽的资源和漏洞，但可能会对目标服务器产生较大的 负载

- 使用方法

  - 点击仪表盘，新建扫描
  - 选择 【爬虫】或 【爬虫与审计】
  - 输入目标 URL
  - 点击 开始

  

##### BP解码模块——Decoder 是 Burp 内置的一个 数据编解码工具

- 模块作用

  - 对数据进行 解码（如 Base64、URL、HTML 实体 等）
  - 对数据进行 编码（如 URL 编码、Base64、Hex、HTML 编码等）
  - 便于分析和构造测试 payload
  - 支持的操作
    - URL：URL  编码与解码（百分号编码 `%20`）
    - HTML：HTML 实体编码与解码（'&lt;', '&gt;'）  
    - Base64：常见的二进制与文本传输格式 
    - ASCII/Hex：十六进制与文本互转
    - Gzip/Deflate 对压缩内容进行解压
    - SHA/MD5：等哈希（只能计算，不能反解）

- 使用方法

  - 可以在数据包中（请求包或响应包），将要编码/解码的数据选中 → 右键 → Send to Decoder
  - 选择要对数据进行的操作（编码或解码）

  

##### BP对比模块——Comparer 是 Burp Suite 用来 对比两段数据差异 的模块

- 模块作用
  - 请求之间的差异（比如两个不同参数请求的区别）
  - 响应之间的差异（比如报错信息 vs 正常信息）
  - 任意文本（复制粘贴进去对比）

- 场景

  - 盲注、布尔型注入测试（响应差异很小，用 Comparer 辅助确认）
  - 认证/越权测试（不同用户请求返回的差别）
  - 响应调试（检查加密参数、隐藏字段的细微变化）

-  使用方法

  - 打开靶场
  - 发送两个数据包，使用BP拦截
  - 将讲个数据包发送到对比模块，选择文字或字节进行对比
  - 即可显示结果

    - 平台地址：https://fofa.info/
  - 奇安信鹰图——奇安信鹰图（Hunter）是奇安信集团推出的网络空间测绘与资产安全管理平台，其核心定位是通过主 动探测、被动数据融合和人工智能技术，构建全球互联网资产动态地图，帮助用户快速发现、分析和 管理暴露在公网的设备与服务。截至 2025 年，鹰图已覆盖超 174 亿资产，支持 1300 + 协议识别，成 为国内网络安全领域资产测绘的标杆工具奇安信集团

##### 空间测绘搜索实战——在搜索的时候每个公司的搜索语法不太相同，但是用法都一样，一定要查阅搜索的手册

- 这里我们以FOFA为例子
- 网站标题搜索
  - 搜索后台登录的网站
  - title="后台登录"

- 网站正文搜索
  - body="ResourceScripts/zh-cn-Login.aspx.js"
- 网站图标搜索
  - 先找到对应的网站，打开F12找到对应的ICO图标请求
  - 在图标出鼠标右键保存图标
  - 将图标保存到系统中
  - 点击搜索即可搜索到同类别网站
- 网站域名搜索
  - 域名搜索，写入主域名即可查询子域名
  - domain="qq.com"

- 语法联合查询

  - 搜索语法提供联合两个条件的查询语法

  - 主要是 && 和 || 比较多，一个是与一个是或

  - 查询对应的资产，并且有域名

    - icon_hash="-759108386" && is_domain=true

    

##### 搜索引擎高级搜索——搜索引擎同样提供了高级搜索的功能，可以更加精准的搜索

- 百度高级搜索

  - 搜索地址：https://www.baidu.com/gaoji/advanced.html
  - 案例1 ：搜索高校的学号PDF 文件
    - 语法："学号" filetype:pdf site:edu.cn
  - 案例2 ：搜索高校后台登录网站
    - 语法：title: ( "后台登录" ) site:edu.cn
  - 案例3 ：搜索qq.com 的子域名
    - 语法： site:qq.com

- 谷歌高级搜索

  - 搜索地址：https://www.google.com/advanced_search

  - 注意：国内无法访问google，因为被屏蔽

  - 高级搜索语法

  - 查找管理员登录页面

    - inurl://admin/login.php

  - 查找后台数据库管理页面

    - inurl:/phpmyadmin/index.php

  - 只在baidu.com 中查找url 中含有 Login的网页

    - site:baidu.com inurl:Login

  - 只返回baidu.com站点上 文件类型为pdf的网页

    - site:baidu.com filetype:pdf

  - 返回所有包含指向 www.baidu.com 的网页

    - link:www.baidu.com

  - 返回与 www.llhc.edu.cn 网页 布局相似的页面

    - related:www.llhc.edu.cn

  - 查找网站后台

    - site:xx.com intext:管理 site:xx.com inurl:login site:xx.com intitle:后台

  - 查看服务器使用的程序

    - site:xx.com filetype:php site:xx.com filetype:asp site:xx.com filetype:jsp site:xx.com filetype:aspx

  - 查看上传漏洞

    - site:xx.com inurl:file site:xx.com inurl:load

    

##### ARL灯塔扫描工具

- ARL灯塔介绍——ARL 灯塔（全称 Asset Reconnaissance Lighthouse，资产侦察灯塔系统）是一款专为网络安全领域设 计的自动化资产发现与风险评估工具，核心功能是帮助安全团队、渗透测试人员快速定位目标组织的 互联网资产（如域名、IP、端口、Web 应用等），并通过多维度扫描识别潜在漏洞和攻击面

- 灯塔安装条件

  - Kali 中安装内存必须大于4G ，灯塔比较吃资源，内存不够启动不起来
  - 服务器必须有网络，并且确保域名能解析
    - ping baidu.com

  - 必须找到服务器对应的IP ifconfig 地址，如果是VPS 就是用公网IP
    - ipconfig

- ARL灯塔安装

  - 下载安装LinuxEnvConfig并且启动
    - git clone https://gitee.com/yijingsec/LinuxEnvConfig.git  
    - cd LinuxEnvConfig  
    - sudo bash LinuxEnvConfig.sh
  - 选择1安装灯塔
  - 输入IP地址，公网VPS输入公网的，Kali输入本地的
  - 等待安装完成，脚本会自动安装并运行ARL，启动完毕后会返回服务访问的URL地址及默认登录账号密码

- ARL灯塔检查

  - ARL一共有五个容器，必须全部处在Up状态，ARL才能正常运行, 如下图所示
  - docker ps -a

- ARL灯塔访问——默认端口  5003 (https), 默认用户名密码 admin / arlpass

  - 在实体机输入——灯塔IP地址:5003
  - 浏览器首次访问时会出现证书错误警告，点击忽略风险继续访问
  - 输入账号和密码：默认用户名密码 admin / arlpass
  - 登录成功

-  ARL灯塔使用

  - 添加任务，输入任务名和对应的信息
    - 关闭 nuclei调用、站点截图、WIH调用
  - 等待灯塔扫描完

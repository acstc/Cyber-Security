##### 目录扫描的概念

- 目录扫描介绍
  - 网站目录扫描是通过 “请求探测” 识别网站服务器上的隐藏资源。其原理是利用包含常见目录名（如 /admin）、文件名（如备份.sql）的字典库，向目标网站批量发送访问请求，再根据服务器返回的状 态码（如 200 代表存在、404 代表不存在），判断是否存在对应目录或文件。
  - 示例： https://www.xxx.com/目录或者文件

- 常见的特殊目录
  - robots.txt——爬虫文件，不允许爬取哪些文件
  - crossdomain.xml 
  - sitemap.xml 
  - 后台目录  
  - 网站安装目录  
  - 网站上传目录  
  - mysql管理页面  
  - phpinfo——敏感信息难利用，SRC一般不收
  - 网站文本编辑器——富文本编辑器
  - 测试文件  
  - 网站备份文件（.rar、.zip、.7z、.tar、.gz、.bak）——可能有源码，代码审计
  - DS_Store文件——l类似git，版本管理，能还原网站源码
  - API接口——swag接口泄露——DV——高危、严重



##### 工具目录扫描

- Dirsearch工具

  - 进入到conda中的python3.9版本
    - conda activate py39
  - 克隆下载dirsearch工具
    - git clone https://gitee.com/yijingsec/dirsearch.git

  - 进入到工具目录下，安装库文件
    - cd dirsearch   
    - python -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
  - 运行工具
    - python dirsearch.py -u https://www.yijinglab.com/ -e*
    - -e(选择扩展名)

- 御剑目录扫描——在网盘中下载工具

  - 打开工具进入【批量扫描后台】
  - 点击添加，输入要扫描的网址
  - 选择字典进行扫描
  - 开始扫描

- JS中提取敏感目录——除了扫描目录和文件之外，在很多的网站JS中也有目录和接口，需要用到第三方工具提取和探测

  - 下载浏览器扩展【FindSomething.zip】
  - 解压压缩包【解压的扩展不要删除】
  - 打开edge浏览器，进入到插件扩展页面，加载压缩扩展
  - 选择【FindSomething】文件夹
  - 找到扩展文件，并且开启
  - 固定到工具栏方便打开
  - 访问目标网站，打开扩展即可看到有用信息

  

##### 网站服务器收集——服务器收集主要是判断服务器使用了什么开发语言、开发框架、中间件、数据库等，方便后续漏洞挖掘

- 在插件市场、搜索【Wappalyzer】插件
- 点击获取安装，即可在浏览器中看到插件
- 找到测试的网站、然后打开工具即可显示服务器相关信息



##### 操作系统判断——操作系统判断主要判断对方的服务器是windows还是Linux，不同的操作系统在后续的渗透中，操作方式不一样

- TTL值判断原理——TTL（Time To Live，生存时间）是 IP 协议中的一个字段，用于限制数据包在网络中的传输时长，核心作用是防止数据包因路由环路等问题无限循环传输，避免占用过多网络资源

  - 其工作机制如下
    - 数据包发送时，发送方（如操作系统、路由器）会给 TTL 设置一个初始值（常见默认值： Windows 系统为 128，Linux/Unix 系统为 64）
    - 数据包每经过一个路由器（网关）转发一次，TTL 值就会自动减 1
    - 若 TTL 值减至 0，该路由器会直接丢弃数据包，并向发送方返回 “超时” 错误信息（如 ICMP 超时 报文）

- TTL值判断操作

  - 打开cmd
  - 输入ping指令
    - ping 域名

  - 判断百度的服务器为【Linux】

    - 判断如下：
      - 0<TTL<64：Linux系统
      - 64<TTL<128：Windows系统

    - Linux严格区分大小写
    - Windows对大小写不敏感

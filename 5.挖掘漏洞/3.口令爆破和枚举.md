##### 弱口令爆破介绍

- 弱口令的定义——弱口令没有严格的标准和准确的定义，通常认为容易被别人猜测到或被破解工具破解的口令均为弱口 令。例如系统出厂默认口令没有修改、密码设置过于简单（如单一使用字母或数字）、使用了生日、 姓名、电话号码等容易被攻击者猜到的信息设置口令，或者设置的口令属于流行口令库中的流行口 令。

  - 示例：
  - 简单数字组合: 000000    111111    11111111  112233  123123
  - 顺序字符组合：abcdef    abcabc    abc123    a1b2c3  aaa111
  - 临近字符组合：123qwe    Qwerty    qweasd 
  - 特殊含含义组合：admin    password  p@ssword  Iloveyou  5201314

- 破解的原理——顾名思义，暴力破解的原理就是使用攻击者自己的用户名和密码字典，一个一个去枚举，尝试是否能够登录

- 破解的场景——后台登录界面、验证码等各种Web应用程序

- 破解的工具——Burp Suite 的 Intruder 模块提供的四种密码破解方式（Sniper、Battering Ram、Pitchfork、Cluster Bomb）在payload  分配逻辑、请求数量、适用场景上存在显著差异，以下结合技术原理与实战案例展 开说明

  - 维度——Sniper——Battering Ram——Pitchfork——Cluster Bomb
  - payload集合数——1个——1个——多个（按顺序组 合）——多个（全排列组 合）
  - 请求数量——位置数×payload数——payload数——min (各集合长 度) ——各集合长度的乘积
  - 字段关联性——无关联——字段值需相同——字段值需顺序关联——字段值完全独立
  - 适用场景——单字段爆破——多字段同值验证——关联字段组合——全量组合爆破    
  - 典型案例——已知用户名爆破密码——测试admin/admin弱口令——用户名+ID组合验证——未知用户名+密码破爆
  - 资源消耗——中等——低——中等——极高（指数级增长）

  

##### 狙击手模式破解（适合知道用户名或密码的情况）

- 破解原理

  - 狙击手模式（Sniper）使用单一 payload 集合，依次替换每个标记位置（如用户名、密码字段），每 次仅修改一个位置，其他位置保持原始值。例如，若标记了两个位置（用户名和密码），字典包含 5 个密码，则会生成 2×5=10次请求，先固定用户名测试所有密码，再固定密码测试所有用户名
  - 情况1 ：只标记1处，如固定用户名 admin ，依次替换密码字段，快速定位弱口令
  - 破解次数为：5次
    - admin  1234567
    - admin  1qazwsx 
    - admin  qwe123q
    - admin  98765432
    - admin  zxcasdq

  - 情况2 ：标记多处，标记账号和密码，同时破解
  - 破解次数为10次
    - xxxx  1234567
    - xxxx  1qazwsx  
    - xxxx  qwe123q  
    - xxxx  98765432  
    - xxxx  zxcasdq    
    - 1234567  xxx
    - 1qazwsx  xxx  
    - qwe123q  xxx  
    - 98765432  xxx  
    - zxcasdq  xxx

  - xxx取决于你抓包时候填写的信息

- 单个破解实操

  - 打开靶场选择弱口令暴力破解
  - 打开BP、先打开抓包再登录，将数据包发送给破解模块，标记密码
  - 选择字典
  - 开始攻击
  - 通过排序观察，正确内容
  - 登录系统验证

- 多个破解实操

  - 打开靶场选择弱口令暴力破解

  - 打开BP、进行抓包，这里输入(admin/123456)将数据包发送给破解模块，标记密码2处，选择字 典

  - 开始攻击，观察返回长度、判断结果

  - 登录系统验证

    

##### 攻城槌模式破解（适合需要重复输入密码的情况）

- 破解原理——攻城槌（Battering Ram）使用单一 payload 集合，同时替换所有标记位置，每个 payload 会填充到所 有标记字段中若标记了用户名和密码字段，字典包含 admin、 test，则会生成两次请求： admin/admin和 test/test

  - 情况1 ：只标记1 处，如固定用户名 admin ，依次替换密码字段，快速定位弱口令
  - 破解次数为：5次
    - admin  1234567
    - admin  1qazwsx 
    - admin  qwe123q
    - admin  98765432
    - admin  zxcasdq

  - 情况2 ：标记多处，标记账号和密码，同时破解
  - 破解次数为5次
    - 1234567  1234567
    - 1qazwsx  1qazwsx  
    - qwe123q  qwe123q  
    - 98765432  98765432  
    - zxcasdq  zxcasdq 
  - xxx取决于你抓包时候填写的信息

- 破解实操
  - 打开靶场选择弱口令暴力破解
  
  - 抓包，选择攻城槌模式、标记2处
  
  - 选择字典，可以看到请求是4次
  
  - 开始攻击，完成后观察返回长度 ()
  
  - 登录系统验证
  
    

##### 干草叉模式破解（适合输入密码和验证码的情况，验证码插件）

- 破解原理——干草叉模式（Pitchfork）使用多个独立 payload  集合，按顺序组合每个集合的元素，即第一个集合的第 1 个元素与第二个集合的第 1 个元素配对，依此类推

  - 例如，用户名集合为 [user1, user2]，密码集合为 [pass1, pass2, pass3]
  - 则生成两次请求： user1/pass1和 user2/pass2，第三个密码 pass3因无对应用户名被忽略

- 破解实操

  - 打开靶场选择弱口令暴力破解
  - 抓包，选择干草叉模式破解、标记2处，账号和密码
  - 选择标记1和对应的字典
  - 选择标记2和对应的字典
  - 开始破解，可以看到账号密码是一一对应的关系
  - 判断结果，尝试登录

  

##### 集束炸弹模式破解（适合不知道账号密码的情况）

- 破解原理——集束炸弹模式（Cluster Bomb）使用 多个独立 payload  集合，生成所有可能的组合（笛卡尔积），即 第一个集合的每个元素与第二个集合的每个元素配对，依此类推

  - 例如，用户名集合有 2 个元素，密码集合有 3 个，则生成 2×3=6次请求
  - user1/pass1、user1/pass2、user1/pass3、user2/pass1、user2/pass2、user2/pass3

- 破解实操

  - 打开靶场选择弱口令暴力破解
  - 抓包，选择集束炸弹模式破解、标记2处，账号和密码
  - 选择标记1和对应的字典
  - 选择标记2和对应的字典
  - 开始破解，可以看到账号密码是交叉对应的关系
  - 判断结果，尝试登录

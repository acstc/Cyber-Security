#### 未授权访问

- 未授权原理
  - 未授权访问（Unauthorized Access） 指用户在未经过身份验证或超出已授权范围的情况下，非法访问 系统资源、数据或功能的安全漏洞。其核心原理是系统未对用户的访问请求进行有效身份验证或权限 校验，导致攻击者可绕过正常认证流程（如未登录访问）或突破权限限制（如越权操作）
  - 通俗来说：就像你家的门锁坏了，陌生人不需要钥匙就能直接推门而入，甚至还能随意翻动你的东 西
- 未授权场景
  - 后台 /  管理界面未验证
    - 后台登录页面可直接跳过，直接访问/admin等管理路径
    - 示例：某系统的/admin/userList接口无需登录即可查看所有用户信息
  - 接口权限校验缺失
    - API 接口未校验用户身份，直接返回敏感数据
      - 如/api/user/123可直接获取 ID=123 的用户手机号、地址等
    - 功能接口未授权即可调用
      - 如/api/deleteUser?id=123无需权限即可删除用户



#### 垂直越权漏洞

- 垂直越权原理

  - 垂直越权（Vertical Privilege Escalation）是权限控制漏洞的一种，指低权限用户通过某种手段，非法 访问或操作高权限用户才能使用的功能
  - 通俗理解：就像公司的普通员工，未经允许擅自进入了总经理的办公室，甚至使用了总经理的权限审 批文件
  - 核心特点：跨越了权限等级（如普通用户 → 管理员 → 系统管理员）

- 垂直越权场景

  - 管理功能未校验权限

    - 普通用户直接访问管理员后台路径（如/admin/userManage）
    - 调用管理员专属 API（如/api/admin/deleteUser）

  - 操作敏感功能无权限校验

    - 低权限用户执行高权限操作（如普通用户删除系统日志、修改他人权限）
    - 示例：某系统中，普通用户通过访问/api/setRole?userId=1&role=admin，将自己升级为管理员

  - 后台接口权限过滤不严

    - 仅验证 "是否登录"，未验证 "是否为高权限角色"
    - 示例：管理员接口仅判断user != null，而未校验user.role == 'admin'

- 越权使用管理员功能

  - 记住数据包的请求参数，切换普通的用户，构造参数，尝试时候能够删除用户数据

  - 构造数据包，进行删除

- 修改请求方式绕过鉴权

  - 选择管理员登录到系统中
  - 选择垂直越权接口绕过，发现管理员可以进行用户添加和降低权限操作
  - 抓取升级为管理员操作数据包
  - 记住数据包的请求参数，切换普通的用户 user2，构造参数，尝试时候是否能够升级管理员操作
    - username=user1&action=upgrade
  - 构造数据包，进行提升 user2用户权限
  - 切换请求方式为 GET请求   （或PUT请求）
  - 刷新浏览器页面

- 请求头绕过鉴权

  - 选择管理员登录到系统中
  - 选择垂直越权认证头绕过，发现管理员可以进行用户添加和降低权限操作
  - 抓取升级为管理员操作数据包

    - username=user1&action=upgrade
  - 构造数据包，进行提升 user3用户权限
  - 添加请求头 Auth: bypass进行尝试

    - role：user 用户权限
    - role：admin管理员权限
